# reads-qc

Контроль качества прочтений секвенирования: расчёт длины, GC-состава и среднего качества каждого прочтения, удаление адаптерной последовательности, фильтрация по порогу качества и длине, запись очищенного FASTA, сводной таблицы TSV, гистограмм и текстового отчёта.

## Назначение

На вход подаются сырые прочтения в формате FASTQ. Программа вычисляет длину, GC-состав и среднее качество (Phred+33), отбрасывает адаптер `AGATCGGAAGAGC`, фильтрует прочтения по качеству (порог 25) и длине (не менее 100 п.н.), а затем сохраняет результаты в каталог `results/`.

## Структура проекта

```text
reads-qc/
├── data/
│   ├── raw/                         входные данные (не в репозитории)
│   └── processed/                   промежуточные данные
├── results/                         отчёты и графики (создаётся при запуске)
├── src/main.py                      точка входа
├── tests/                           тесты
├── .gitignore
├── README.md

```

Каталог `results/` не хранится в репозитории: это результат работы программы, который восстанавливается запуском.

## Требования

- Python 3.10 или новее;
- Git;
- Windows 10/11, Linux или macOS.

## Установка

```bash
git clone <адрес репозитория> reads-qc
cd reads-qc
python -m venv .venv
```

Далее активируйте окружение:

**Windows (PowerShell):**
```powershell
# Если появляется ошибка "выполнение сценариев отключено", выполните:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
# Затем активируйте:
.venv\Scripts\Activate.ps1
```

**Windows (cmd.exe):**
```cmd
.venv\Scripts\activate.bat
```

**Linux / macOS (bash):**
```bash
source .venv/bin/activate
```

После активации установите зависимости:
```bash
python -m pip install -r requirements.txt
```

## Ограничения и известные проблемы

В соответствии с правилом пяти правок, на данном этапе были исправлены только критические дефекты. Остальные проблемы зафиксированы здесь как технический долг:

1. **Подавление ошибок парсинга:** в функции `main()` используется `except: pass`. Если строка качества не читается, прочтение молча пропускается.
2. **Магические константы:** порог качества (25), минимальная длина (100), длина адаптера (13) жёстко зашиты в код.
3. **Неинформативные имена переменных:** `r`, `s`, `q`, `z`, `x`, `g1`, `g2`, `ll`.
4. **Отсутствие контекстных менеджеров:** файлы открываются через `open()`, а не `with open()`.
5. **Мертвый код:** закомментированные импорты `pandas` и `Bio.SeqIO`.
6. **Отсутствие тестов:** автоматические тесты отсутствуют.
